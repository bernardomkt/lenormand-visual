# Lenormand Visual

Landing page em português, inglês e italiano, com imagens localizadas.

## Desenvolvimento
Requer Node.js e pnpm. Execute `pnpm install --frozen-lockfile`, `pnpm dev`, `pnpm check` e `pnpm build`.

## Estrutura
`src/`: aplicação React, textos e mapa de imagens. `public/`: 21 imagens originais e 40 localizações. Os ficheiros de venda ficam fora deste repositório público.

## Estado
Versão visual aprovada, com compras desactivadas e contador estático. Não processa pagamentos nem recolhe contactos. Preços, condições e testemunhos reproduzem a referência fornecida para revisão, sem certificação independente. Nenhum script de tracking da referência é executado.

As traduções visuais foram editadas com IA e podem ter pequenas diferenças nos pormenores.

A hospedagem é gerida separadamente do GitHub. O código pode ser alojado em qualquer serviço de sites estáticos que suporte fallback para index.html.
